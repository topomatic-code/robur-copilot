# Шаблон документирования функций

Функции документированы следующим образом:

## 📦 Функция

```lisp
(название_функции аргументы)
```

## 📄 Описание

Краткое описание назначения функции.

## 📥 Аргументы

- `(тип)` аргумент1 - что означает;
- `(тип)` аргумент2 - аналогично.

## 📈 Возвращает

`(тип)` Описание результата, например solid-модель, плоский контур и т.д.

## 💬 Примечания

Особенности поведения, ограничения, совместимость.

## 🧾 Пример использования

```lisp
(название_функции значение1 значение2)
```
