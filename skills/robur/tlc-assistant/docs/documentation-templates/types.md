# Шаблон документирования типов Tlc

Типы Tlc документированы следующим образом:

## 🏷️ Название

Название типа.

## 📖 Описание

Описание назначения типа и того, как он используется.

## ♻️ Наследует тип

Базовый тип, если данный тип наследует функционал от другого типа.

Данный раздел является опциональным.

Все Tlc-функции, применимые к экземплярам базового типа, также применимы и к экземплярам текущего типа.

## ⚙️ Поведение (не доступно из Tlc)

Описание поведения типа.

Вызывать методы экземпляров типов напрямую из Tlc нельзя, но знание их устройства необходимо для понимания особенностей применения типов Tlc.

## ⚡ Функции, взаимодействующие с экземплярами типа (доступно в Tlc)

Перечисление функций из библиотеки Tlc, позволяющих взаимодействовать с экземплярами данного типа в скриптах Tlc.
