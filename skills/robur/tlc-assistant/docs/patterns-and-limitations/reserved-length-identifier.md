# Определение идентификатора длины - "length"

## 🧷 Тема

Определение идентификатора длины - "length".

## 📝 Описание

Идентификатор length уже зарезервирован в tlc, поэтому его нельзя использовать для объявления свойств, переменных, функций и т.д.
Если необходимо создать свойство с тегом length, следует заменить тег на другой (например len).

## 🚫 BAD (ANTIPATTERN, DO NOT COPY)

```lisp
(defproperty length 1.0 "Длина" (v-property-length-m))
```

## 🟢 GOOD (PATTERN)

```lisp
(defproperty len 1.0 "Длина" (v-property-length-m))
```
