# Создание уникальных имен. Вывод блоков чертежа плана с уникальными именами

## 🧷 Тема

Создание уникальных имен. Вывод блоков чертежа плана с уникальными именами.

## 📝 Описание

В ряде случаев возникает необходимость генерации уникальных имен. В этом случае может помочь функция (create-guid).
Одной из таких задач является вывод чертежа плана модели, с уникальным именем блока.
Это необходимо при работе с динамическими чертежами и экспортом в форматы: *.dxf, *.dwg.
Если один и тот же Tlc-компонент будет вставлен несколько раз в пространство проекта, то по умолчанию у блоков чертежа плана этих компонентов будет одинаковое имя.
Форматы dxf и dwg хранят все блоки в таблице блоков, а значит, если у разных моделей (созданных по одному скрипту) имена блоков будут совпадать - это вызовет колизии и "сломает" отрисовку.

## 🟢 GOOD (PATTERN)

```lisp
(defcomponent "Component with custom block name" "SmdxElement"
  (setproperty block_name (format "plan_block_{0}" (create-guid)) "Имя блока плана" (v-property-string))
  (defgeometry
    (v-sphere 1)))
```
