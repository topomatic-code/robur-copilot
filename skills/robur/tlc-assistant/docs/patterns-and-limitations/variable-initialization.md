# Инициализация и вычисление значений переменных

## 🧷 Тема

Инициализация и вычисление значений переменных.

## 📝 Описание

Если нужно инициализировать переменную значением, вычисленным на основании значений других переменных,
определенных в этой же форме let, нельзя делать это напрямую.
Корректно использовать let совместно с setq.

## 🚫 BAD (ANTIPATTERN, DO NOT COPY)

```lisp
(let ((a 2)
      (b 3)
      (c (+ a b)))
)
```

## 🟢 GOOD (PATTERN)

```lisp
; 1 способ
(let ((a 2)
      (b 3)
      c)
  (setq c (+ a b))
)
```

Дополнительный вариант:

```lisp
; 2 способ
(let (a b c)
  (setq a 2
        b 3
        c (+ a b))
)
```
