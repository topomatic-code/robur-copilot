# Имя блока

## 🏷️ Название

Имя блока.

## 📖 Описание

Сообщает платформе Robur о том, какое имя блока нужно использовать при формировании чертежа плана Tlc-модели.

## ⌨️ Синтаксис

```lisp
(defproperty block_name "Имя блока на чертеже" "Имя блока" (v-property-string))
```

## 🛑 Правила

Свойство должно иметь идентификатор "block_name" и быть типа "v-property-string".

## 📈 Возвращает

`(string)` Значение свойства.
