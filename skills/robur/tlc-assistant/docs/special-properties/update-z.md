# Обновлять отметку

## 🏷️ Название

Обновлять отметку.

## 📖 Описание

Сообщает платформе Robur о необходимости обновления отметки точки вставки текущей TLC-модели в случае изменения поверхности, на которой она размещена/спроецирована.
В случае изменения отметок поверхности (для пересчета отметок TLC-моделей) необходимо воспользоваться функцией Robur в меню Вид->Освежить.
Значение true - обновлять, false - не обновлять.

## ⌨️ Синтаксис

```lisp
(defproperty update_z true "Обновлять отметку" (v-property-logic))
```

## 🛑 Правила

Свойство должно иметь идентификатор "update_z" и быть типа "v-property-logic".

## 📈 Возвращает

`(bool)` Значение свойства.
