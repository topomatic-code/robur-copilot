# Полилиния по точкам

## 🏷️ Название

Полилиния по точкам.

## 📖 Описание

Позволяет запросить у пользователя ввод полилинии по точкам.
В данном случае происходит следующее:
1. Происходит первое выполнение всего скрипта. Платформа Robur "видит", какие свойства создал пользователь. Специальное свойство имеет значение nil.
2. Обнаруживается специальное свойство запроса полилинии по точкам.
3. Платформа предлагает пользователю ввести полилинию по точкам на плане (вид сверху).
4. После ввода полилинии платформа присваивает специальному свойству в качестве значения объект (типа typed_object), представляющий введенную полилинию.
5. Скрипт выполняется второй раз. Специальное свойство имеет значение, отличное от nil.

У пользователя есть возможность изменить введенную полилинию в дальнейшем: изменить положение вершин (за счет перемещения грипов на плане), добавить/удалить точки и т.д.

После редактирования полилинии скрипт будет выполнен заново, с обновленным значением специального свойства.
У объекта (typed_object) c Smdx-типом "SmdxManualPolyline", представляющего полилинию, есть 2 свойства: "verteces" и "mverteces".

verteces:iterable<typed_object> - объект, представляющий набор 3d-точек.

mverteces:iterable<typed_object> - объект, представляющий набор 2d-вершин (с закруглениями bugle) плана.

Несмотря на то, что точки вводятся пользователем в мировой системе координат проекта, в свойство они попадают уже с пересчетом в локальную систему координат Tlc-модели. Таким образом в Tlc-скриптах можно использовать точки "как есть", без каких-либо дополнительных преобразований.

## ⌨️ Синтаксис

```lisp
(defproperty property_name nil "Имя свойства" (v-property-typed "SmdxManualPolyline"))
```

## 🛑 Правила

Начальное значение свойства должно быть nil.

Тип свойства должен быть (v-property-typed "SmdxManualPolyline").

## 📈 Возвращает

`(typed_object)` Объект, представляющий полилинию.

## 🧾 Пример использования

```lisp
(defcomponent "Canal" "SmdxElement"
  ;; запрашиваем ввод полилинии по точкам у пользователя
  (defproperty polyline nil "Ось канала" (v-property-typed "SmdxManualPolyline"))
  ;; нужна проверка, т.к. при первом выполнении скрипта polyline == nil
  (when (eql (eql polyline nil) false)
    (print (format "Длина полилинии: {0} м" (v-curve-length polyline)))
    (let (points_obj vertices_obj)
      (setq points_obj   (getproperty polyline "verteces")   ; объект, представляющий набор 3d-точек
            vertices_obj (getproperty polyline "mverteces")) ; объект, представляющий набор 2d-вершин плана
      ;; 3d-вершины полилинии
      (v-for (point_obj points_obj)
        ;; point_obj - объект, представляющий 3d-точку
        (let (x y z)
          (setq x (getproperty point_obj "x")  ; у объекта точки запрашиваем значение свойства x
                y (getproperty point_obj "y")  ; у объекта точки запрашиваем значение свойства y
                z (getproperty point_obj "z")) ; у объекта точки запрашиваем значение свойства z
          (print (format "Точка: x={0}, y={1}, z={2}" x y z))))
      ;; 2d-вершины полилинии в плане с закруглениями (bugle)
      (v-for (vertex_obj vertices_obj)
        ;; vertex_obj - объект, представляющий 2d-вершину в плане с параметром bugle
        (let (x y bugle)
          (setq x     (getproperty vertex_obj "x")      ; у объекта вершины запрашиваем значение свойства x
                y     (getproperty vertex_obj "y")      ; у объекта вершины запрашиваем значение свойства y
                bugle (getproperty vertex_obj "bugle")) ; у объекта вершины запрашиваем значение свойства bugle
          (print (format "Вершина: x={0}, y={1}, bugle={2}" x y bugle)))))
    (defgeometry
      (v-sweep-miter
        (v-profile-compound
          (v-profile-rect 1.0)
          (v-profile-rect 1.5))
        polyline))))
```
