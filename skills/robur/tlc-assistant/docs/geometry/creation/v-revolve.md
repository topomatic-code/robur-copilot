# `v-revolve`

## 📦 Функция

```lisp
(v-revolve profile)
(v-revolve profile span)
(v-revolve profile span angle)
```

## 📄 Описание

Создание 3d-тела путём вращения профиля относительно оси OZ (Нормаль: X=0, Y=0, Z=1).

## 📥 Аргументы

- `(profile)` `profile` - вращаемый профиль;
- `(double)` `span` - угол вращения (по умолчанию 360);
- `(double)` `angle` - угол начала вращения (по умолчанию 0).

## 📈 Возвращает

`(geometry_object)` 3d-тело.

## 💬 Примечания

Создание 3д (X'Y'Z') тела осуществляется путем вращения 2д (XY) профиля вокруг оси Z'.

При этом начальное положение профиля в 3д пространстве тела (при angle = 0) определяется следующим образом: X' = X, Y' = 0, Z' = Y.

При span > 0 вращение осуществляется против ЧС.

При span < 0 вращение осуществляется по ЧС.

Параметр angle позволяет задать начальное положение профиля за счет поворота вокруг оси Z' (> 0 - против ЧС, < 0 - по ЧС).

Таким образом: span = 45, angle = 20, означает - создание 3д тела, путем вставки XY профиля в координаты X'Y'Z' с поворотом начального сечения на 20 градусов против ЧС и вращением вставленного сечения на 45 градусов против ЧС.

## 🧾 Пример использования

Создание тела полным вращением фигурного профиля на 360° вокруг оси OZ:

```lisp
(let
  ; Определение профиля
  ((profile (v-profile-shape
              (vec 0 0) (vec 0 1)
              (vec 0 1) (vec 0.5 1)
              (vec 0.5 1) (vec 1 0)
              (vec 1 0) (vec 0 0))))
  ; Определение блока геометрии
  (defgeometry
    ; Создание 3D-тела путём вращения профиля относительно оси OZ
    (v-revolve profile)))
```

Создание тела поворотом фигурного профиля на 120° вокруг оси OZ:

```lisp
(let
  ; Определение профиля
  ((profile (v-profile-shape
              (vec 0 0) (vec 0 1)
              (vec 0 1) (vec 0.5 1)
              (vec 0.5 1) (vec 1 0)
              (vec 1 0) (vec 0 0))))
  ; Определение блока геометрии
  (defgeometry
    ; Создание 3D-тела путём вращения профиля относительно оси OZ
    ; с назначением величины угла вращения
    (v-revolve profile 120)))
```

Создание тела поворотом фигурного профиля на 120° с начальным углом 170°:

```lisp
(let
  ; Определение профиля
  ((profile (v-profile-shape
              (vec 0 0) (vec 0 1)
              (vec 0 1) (vec 0.5 1)
              (vec 0.5 1) (vec 1 0)
              (vec 1 0) (vec 0 0))))
  ; Определение блока геометрии
  (defgeometry
    ; Создание 3D-тела путём вращения профиля относительно оси OZ
    ; с назначением величины угла вращения и угла начала вращения
    (v-revolve profile 120 170)))
```
