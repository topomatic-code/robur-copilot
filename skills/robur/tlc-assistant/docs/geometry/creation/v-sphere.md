# `v-sphere`

## 📦 Функция

```lisp
(v-sphere radius)
```

## 📄 Описание

Создание сферического 3d-тела с заданным радиусом.

## 📥 Аргументы

- `(double)` `radius` - радиус сферы.

## 📈 Возвращает

`(geometry_object)` 3d-тело.

## 💬 Примечания

```text
=== Схема определения сферы (проекции) ===
Центр сферы: O(0;0;0)
r = radius
Проекция на плоскость XOY (Z = 0):
                        Y+
                        ↑
                        │
                        │
                        │
                        ●Py+(0;+r;0)
                    ╱   │   ╲
                  ╱     │     ╲
                ╱       │       ╲
────Px-(-r;0;0)●─────O(0;0)──────●Px+(+r;0;0)──────→ X+
                ╲       │       ╱
                  ╲     │     ╱
                    ╲   │   ╱
                        ●Py-(0;-r;0)
                        │
                        │
                        │
Уравнение в плоскости XOY:
x^2 + y^2 = r^2
Проекция на плоскость XOZ (Y = 0):
                        Z+
                        ↑
                        │
                        │
                        │
                        ●Pz+(0;0;+r)
                    ╱   │   ╲
                  ╱     │     ╲
                ╱       │       ╲
────Px-(-r;0;0)●─────O(0;0)──────●Px+(+r;0;0)──────→ X+
                ╲       │       ╱
                  ╲     │     ╱
                    ╲   │   ╱
                        ●Pz-(0;0;-r)
                        │
                        │
                        │
Уравнение в плоскости XOZ:
x^2 + z^2 = r^2
Общее определение сферы:
x^2 + y^2 + z^2 = r^2
```

## 🧾 Пример использования

```lisp
; Определение блока геометрии
(defgeometry
  ; Создание 3D-тела сферической формы
  (v-sphere 0.5))
```
