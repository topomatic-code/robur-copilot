# `v-sweep`

## 📦 Функция

```lisp
(v-sweep profile curve)
(v-sweep profile curve_object)
(v-sweep profile curve orientation)
(v-sweep profile curve_object orientation)
```

## 📄 Описание

Создание 3d-тела путём выдавливания профиля вдоль кривой.

## 📥 Аргументы

- `(profile)` `profile` - выдавливаемый профиль;
- `(curve)` `curve` - кривая;
- `(typed_object)` `curve_object` - объект, представляющий кривую;
- `(vector3)` `orientation` - направление профиля.

## 📈 Возвращает

`(geometry_object)` 3d-тело.

## 💬 Примечания

```text
=== Схема ориентации профиля при вставке сечений ===
Исходный 2D-профиль (XOY):
          Y+
          ↑
          │
          │   ●p(x;y)
          │
─────────O┼────────→ X+
          │
          │
Вставка профиля в 3D-пространство:
              Y'+
              ↑
              │
 p'(x;y;z)●   │
              │
X'+ ←────────O┼────────
              │
              │
(Z направлена "от наблюдателя" и совпадает с касательной кривой).
2D-профиль определяется в плоскости XOY с началом координат O(0;0),
где ось X направлена вправо, а ось Y — вверх.
При выполнении операции v-sweep профиль последовательно вставляется
вдоль кривой. Для каждого сечения строится локальная система координат,
в которой:
- ось Z' совпадает с касательной к кривой в точке вставки;
- оси X' и Y' формируются ортогонально к Z' с сохранением правой
  системы координат.
В результате такой реконструкции базиса происходит изменение направления
оси X профиля: визуально она будет направлена влево относительно
наблюдателя, хотя в исходном 2D-профиле была направлена вправо.
Это поведение является нормальным и обусловлено:
- использованием векторного произведения при построении базиса;
- необходимостью сохранения правой системы координат в 3D;
- корректной ориентацией нормалей и граней результирующего тела.
```

## 🧾 Пример использования

```lisp
(let
  (
    ; Определение профиля
    (profile (v-profile-rotate (v-profile-p 0.01 0.25) 90))
    ; Определение кривой
    (arc (v-curve-arc (vec 0 0 0) (vec 0 1 0) (vec -1 0 0) 120)))
  ; Определение блока геометрии
  (defgeometry
    ; Создание 3D-тела путём выдавливания профиля вдоль кривой
    (v-sweep profile arc (vec 0 1 0))))
```
