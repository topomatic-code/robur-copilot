# `v-sweep-miter`

## 📦 Функция

```lisp
(v-sweep-miter profile curve)
(v-sweep-miter profile curve_object)
(v-sweep-miter profile curve mode)
(v-sweep-miter profile curve_object mode)
```

## 📄 Описание

Создание 3d-тела путём выдавливания профиля вдоль кривой с созданием
miter-соединений в местах переломов кривой.

## 📥 Аргументы

- `(profile)` `profile` - выдавливаемый профиль;
- `(curve)` `curve` - кривая;
- `(typed_object)` `curve_object` - объект, представляющий кривую;
- `(integer)` `mode` - способ ориентации сечений при вставке.
            Принимает значения: - 0 - фиксированное сечение;
                                - 1 - скручивание сечений (используется по умолчанию);
                                - 2 - вертикально ориентированное сечение.

## 📈 Возвращает

`(geometry_object)` 3d-тело.

## 💬 Примечания

Функция предназначена для моделирования трубопроводов, каналов и прочих сооружений,
где необходимо создавать miter-соединения в местах переломов траектории вытягивания.

Функция работает только с константными профилями (v-profile-rect, v-profile-round, v-profile-shape и др.).

Способ ориентирования 2d-профилей при вставке в 3d-пространство аналогичен способу, используемому функцией v-sweep (см. примечания v-sweep).

## 🧾 Пример использования

```lisp
; Создание трубы путем вытягивания кольцевого профиля вдоль прямой
(defcomponent "Труба" "SmdxElement"
  (defgeometry
    (v-sweep-miter
      (v-profile-compound
        (v-profile-round 1.10)
        (v-profile-round 1.25))
      (v-curve-straight (vec) (vec 5.0 0.0 0.0)))))
```
