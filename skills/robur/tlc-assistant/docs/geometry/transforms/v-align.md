# `v-align`

## 📦 Функция

```lisp
(v-align offset orientation angle bodies)
(v-align offset orientation angle body_1 body_2 ... body_N)
(v-align offset orientation direction bodies)
(v-align offset orientation direction body_1 body_2 ... body_N)
```

## 📄 Описание

Изменение положения 3d-тел в пространстве.

## 📥 Аргументы

- `(vector3)` `offset` - вектор смещения;
- `(vector3)` `orientation` - новое направление оси Z локальной системы координат XYZ (должен быть ненулевым вектором);
- `(double)` `angle` - угол вращения вокруг новой оси Z в градусах;
- `(vector3)` `direction` - вектор вращения;
- `(list)` `bodies` - список изменяемых 3d-тел;
- `(geometry_object)` `body_#` - изменяемое 3d-тело.

## 📈 Возвращает

`(geometry_object)` 3d-тело.

## 💬 Примечания

```text
=== Схема локальной системы координат и преобразований для перегрузок вида (v-align offset orientation angle ...) ===
Функция выполняет реконструкцию локальной системы координат тела
на основании вектора orientation с последующим вращением на угол angle
вокруг оси orientation (проходящей через начало координат O) и переносом на offset.
Даже при angle = 0 тело будет переориентировано,
если orientation отличается от исходного направления осей.
Если angle > 0 - вращение происходит против ЧС.
Если angle < 0 - вращение происходит по ЧС.
Начало локальной системы координат: O(0;0;0).
Вид сверху XOY (Z направлена вверх к наблюдателю).
Положим: offset = (2;3;0), orientation = (0;0;1) - для упрощения схемы совпадает с исходным направлением оси Z.
                    Y+
                    ↑
                    │
                    │       ↺ angle > 0 (против ЧС)
                    │       ●p(2;3;0)
                    │       ↻ angle < 0 (по ЧС)
                    │
                    │
─────────────────O(0;0)───────────────→ X+
                    │
                    │
                    │
                    │
                    │
                    │
                    │
Некоторые следствия поведения функции:
При offset = (0;0;0), orientation = (0;0;1), angle = 0: исходное тело не изменится.
При offset = (1;1;0), orientation = (0;0;1), angle = 0: исходное тело переместится на 1 м по оси X, а также на 1 м по оси Y.
При offset = (0;0;0), orientation = (0;0;1), angle = 15: исходное тело повернется вокруг своего начала координат на 15 градусов против ЧС.
При offset = (0;0;0), orientation = (0;-1;0), angle = 0: исходное тело повернется вокруг оси X на 90 градусов по ЧС (при направлении взгляда на плоскость YOZ, при X направленным от наблюдателя).
При offset = (0;0;0), orientation = (0;1;0), angle = 0: исходное тело повернется вокруг оси X на 90 градусов против ЧС (при направлении взгляда на плоскость YOZ, при X направленным от наблюдателя),
а также зеркально отразится относительно оси Y.
Поведение перегрузок вида (v-align offset orientation direction ...) схоже с поведением (v-align offset orientation angle ...), но в данном случае
3d-тело будет развёрнуто в направлении вектора, полученного в результате векторного произведения orientation и direction.
```

## 🧾 Пример использования

Переориентация двух тел по вектору `(1, 1, 0)` с поворотом на 45°; тела передаются в виде списка:

```lisp
(let
  (
    ; Список 3D-тел
    (bodies (list
              (v-extrude (v-profile-round 0.4) (vec 0 0 3))
              (v-extrude (v-profile-round 0.4) (vec 0 1 0)))))
  ; 3D-тело с изменённым положением
  (v-align (vec) (vec 1.0 1.0) 45 bodies)
  ; или
  ; (v-align (vec) (vec 1.0 1.0) (vec -1.0 1.0 1.0) bodies))
```

Переориентация двух тел по вектору `(1, 1, 0)` с поворотом на 45°; тела передаются отдельными аргументами:

```lisp
(let
  (
    ; 3D-тело
    (body1 (v-extrude (v-profile-round 0.4) (vec 0 0 3)))
    ; 3D-тело
    (body2 (v-extrude (v-profile-round 0.4) (vec 0 1 0))))
  ; 3D-тело с изменённым положением
  (v-align (vec) (vec 1.0 1.0) 45 body1 body2)
  ; или
  ; (v-align (vec) (vec 1.0 1.0) (vec -1.0 1.0 1.0) body1 body2))
```
