# `v-entity-text`

## 📦 Функция

```lisp
(v-entity-text text)
(v-entity-text text height)
```

## 📄 Описание

Создание примитива «текст» с текущим текстовым стилем.

## 📥 Аргументы

- `(string)` `text` - текст;
- `(double)` `height` - высота текста (по умолчанию равна 1.0).

## 📈 Возвращает

`(entity)` Примитив.

## 🧾 Пример использования

```lisp
; Определение вида
(defview
  ; Вид сверху (план)
  (v-top)
  ; Примитив текст
  (v-entity-text "Текст" 2.5))
```
