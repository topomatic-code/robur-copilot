# `v-entity-text-styled`

## 📦 Функция

```lisp
(v-entity-text-styled text height justify id title)
```

## 📄 Описание

Создание примитива «стилизованный текст».

## 📥 Аргументы

- `(string)` `text` - текст;
- `(double)` `height` - высота текста (по умолчанию равна 1.0);
- `(integer)` `justify` - выравнивание. Допустимые значения:
                                    - 0 - Влево;
                                    - 1 - Центр;
                                    - 2 - Вправо;
                                    - 3 - Выровненный;
                                    - 4 - Середина;
                                    - 5 - По ширине;
                                    - 6 - Вверх влево;
                                    - 7 - Вверх по центру;
                                    - 8 - Вверх вправо;
                                    - 9 - Середина влево;
                                    - 10 - Середина по центру;
                                    - 11 - Середина вправо;
                                    - 12 - Вниз влево;
                                    - 13 - Вниз по центру;
                                    - 14 - Вниз вправо;
- `(string)` `id` - идентификатор стиля оформления;
- `(string)` `title` - заголовок стиля оформления.

## 📈 Возвращает

`(entity)` Примитив.

## 💬 Примечания

Аргументы id и title не имеют отношения к текстовым стилям настраиваемым в меню «Формат» → «Текстовые стили».
Эти аргументы служат для определения стиля оформления расположенного в настройках программы в подразделе «Оформление» → «Текст».
Если стиль оформления с указанным id не найден, то для этого id создаётся новый стиль оформления с указанным заголовком (title)
и высотой текста (height). Пример ниже добавит новый стиль оформления.

## 🧾 Пример использования

```lisp
; Определение вида
(defview
  ; Вид сверху (план)
  (v-top)
  ; Примитив стилизованный текст
  (v-entity-text-styled "Текст" 2 2 "custom_style_id" "Мой стиль оформления"))
```
