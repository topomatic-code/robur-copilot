# `v-entity-polyline`

## 📦 Функция

```lisp
(v-entity-polyline positions)
(v-entity-polyline positions closed)
(v-entity-polyline positions closed width)
```

## 📄 Описание

Создание примитива «полилиния».

## 📥 Аргументы

- `(dynamic)` `positions` - список или массив точек;
- `(bool)` `closed` - закрыт ли контур;
- `(double)` `width` - толщина линии (по умолчанию равна 0.0).

## 📈 Возвращает

`(entity)` Примитив.

## 💬 Примечания

В качестве набора векторов используются векторы типа vector3.
Компоненты X,Y — задают положение вершины, а параметр Z — задает значение Bugle (скругление
сегмента между текущей вершиной и следующей). Bugle — смещение наиболее удаленной точки дуги относительно сегмента,
образованного текущей и следующей вершиной. Отрицательное значение Bugle смещает дугу влево относительно сегмента, а
положительное — вправо.

## 🧾 Пример использования

```lisp
; Определение вида
(defview
  ; Вид сверху (план)
  (v-top)
  ; Примитив полилиния заданный списком векторов
  (v-entity-polyline
    (list
      (vec -1.0  1.0 -0.2) ; значение -0.2 задает дугу между 0 и 1 вершинами, смещенную влево на 0.2 м
      (vec  1.0  1.0)
      (vec  1.0 -1.0)
      (vec -1.0 -1.0))
    true
    0.05))
```

Дополнительный пример:

```lisp
; Определение вида
(defview
  ; Вид сверху (план)
  (v-top)
  ; Примитив полилиния заданный массивом векторов
  (v-entity-polyline
    (array
      (vec -1.0  1.0 -0.2) ; значение -0.2 задает дугу между 0 и 1 вершинами, смещенную влево на 0.2 м
      (vec  1.0  1.0)
      (vec  1.0 -1.0)
      (vec -1.0 -1.0))
    true
    0.05))
```
