# `vec`

## 📦 Функция

```lisp
(vec)
(vec x)
(vec x y)
(vec x y z)
```

## 📄 Описание

Создание вектора.

## 📥 Аргументы

- `(double)` `x` - координата X (по умолчанию равна 0.0);
- `(double)` `y` - координата Y (если значение не задано, то возвращается вектор со значением аргумента x по всем трём осям);
- `(double)` `z` - Координата Z (по умолчанию равна 0.0).

## 📈 Возвращает

`(vector3)` 3d-вектор.

## 🧾 Пример использования

```lisp
; Создание нулевого вектора
(vec)
; Создание вектора с координатами X = 10, Y = 10, Z = 10
(vec 10)
; Создание вектора с координатами X = 10, Y = 5, Z = 0
(vec 10 5)
; Создание вектора с координатами X = 10, Y = 5, Z = 2
(vec 10 5 2)

```
