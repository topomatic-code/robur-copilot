# `vec-len`

## 📦 Функция

```lisp
(vec-len vector)
```

## 📄 Описание

Вычисление длины вектора.

## 📥 Аргументы

- `(vector3)` `vector` - вектор.

## 📈 Возвращает

`(double)` Длина вектора.

## 🧾 Пример использования

```lisp
(let
  ; Создание векторов
  ((vector (vec 10 5 2)))
  ; Вывод в командную строку
  (print
    ; Длина вектора
    (vec-len vector)))

; Результат вывода в окно командной строки:
; 11.3578166916005

```
