# `vec-z`

## 📦 Функция

```lisp
(vec-z vector)
```

## 📄 Описание

Получение координаты Z вектора.

## 📥 Аргументы

- `(vector3)` `vector` - вектор.

## 📈 Возвращает

`(double)` Значение координаты Z.

## 🧾 Пример использования

```lisp
(let
  ; Создание вектора
  ((vector (vec 10 5 2)))
  ; Вывод в командную строку
  (print
    ; Значение координаты Z вектора
    (vec-z vector)))

; Результат вывода в окно командной строки:
; 2

```
