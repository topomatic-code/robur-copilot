# `vec-x`

## 📦 Функция

```lisp
(vec-x vector)
```

## 📄 Описание

Получение координаты X вектора.

## 📥 Аргументы

- `(vector3)` `vector` - вектор.

## 📈 Возвращает

`(double)` Значение координаты X.

## 🧾 Пример использования

```lisp
(let
  ; Создание вектора
  ((vector (vec 10 5 2)))
  ; Вывод в командную строку
  (print
    ; Значение координаты X вектора
    (vec-x vector)))

; Результат вывода в окно командной строки:
; 10

```
