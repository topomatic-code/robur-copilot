# `vec-y`

## 📦 Функция

```lisp
(vec-y vector)
```

## 📄 Описание

Получение координаты Y вектора.

## 📥 Аргументы

- `(vector3)` `vector` - вектор.

## 📈 Возвращает

`(double)` Значение координаты Y.

## 🧾 Пример использования

```lisp
(let
  ; Создание вектора
  ((vector (vec 10 5 2)))
  ; Вывод в командную строку
  (print
    ; Значение координаты Y вектора
    (vec-y vector)))

; Результат вывода в окно командной строки:
; 5

```
