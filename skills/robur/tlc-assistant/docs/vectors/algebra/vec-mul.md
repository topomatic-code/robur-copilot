# `vec-mul`

## 📦 Функция

```lisp
(vec-mul vector multiplier)
```

## 📄 Описание

Умножение вектора на скаляр.

## 📥 Аргументы

- `(vector3)` `vector` - умножаемый вектор;
- `(double)` `multiplier` - множитель.

## 📈 Возвращает

`(vector3)` Результирующий вектор.

## 🧾 Пример использования

```lisp
(let
  ; Создание векторов
  ((vector (vec 1 2.5 5)))
  ; Вывод в командную строку
  (print
    ; Вектор умноженный на скаляр
    (vec-mul vector 4.125)))
; Результат вывода в окно командной строки:
; {X:4,125 Y:10,3125 Z:20,625}
```
