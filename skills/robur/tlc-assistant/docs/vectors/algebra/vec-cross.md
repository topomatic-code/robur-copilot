# `vec-cross`

## 📦 Функция

```lisp
(vec-cross vector_1 vector_2)
```

## 📄 Описание

Вычисление векторного произведения.

## 📥 Аргументы

- `(vector3)` `vector_#` - вектор.

## 📈 Возвращает

`(vector3)` Векторное произведение.

## 🧾 Пример использования

```lisp
(let
  ; Создание векторов
  (
    (vector (vec 10 5 2))
    (vector2 (vec 3 10 0)))
  ; Вывод в командную строку
  (print
    ; Векторное произведение
    (vec-cross vector vector2)))

; Результат вывода в окно командной строки:
; {X:-20 Y:6 Z:85}

```
