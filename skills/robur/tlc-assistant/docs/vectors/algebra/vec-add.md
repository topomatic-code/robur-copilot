# `vec-add`

## 📦 Функция

```lisp
(vec-add vector_1 ... vector_N)
```

## 📄 Описание

Сложение векторов.

## 📥 Аргументы

- `(vector3)` `vector_#` - складываемые векторы.

## 📈 Возвращает

`(vector3)` Результирующий вектор.

## 🧾 Пример использования

```lisp
(let
  ; Создание векторов
  (
    (vector (vec 1))
    (vector2 (vec "5,2"))
    (vector3 (vec 0 0 1))
    (vector4 (vec 2 2)))
  ; Вывод в командную строку
  (print
    ; Суммарный вектор
    (vec-add vector vector2 vector3 vector4)))
; Результат вывода в окно командной строки:
; {X:8,2 Y:8,2 Z:7,2}

```
