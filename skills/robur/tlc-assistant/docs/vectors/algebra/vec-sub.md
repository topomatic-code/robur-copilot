# `vec-sub`

## 📦 Функция

```lisp
(vec-sub init_vector)
(vec-sub init_vector vector_1 ... vector_N)
```

## 📄 Описание

Вычитание векторов.

## 📥 Аргументы

- `(vector3)` `init_vector` - вектор из которого производится вычитание;
- `(vector3)` `vector_#` - вычитаемые векторы. Если не заданы, то возвращается отрицательный вектор аргумента init_vector.

## 📈 Возвращает

`(vector3)` Результирующий вектор.

## 🧾 Пример использования

```lisp
(let
  ; Создание векторов
  (
    (init (vec 5))
    (vector (vec 1))
    (vector2 (vec "5,2"))
    (vector3 (vec 0 0 1)))
  ; Вывод в командную строку
  (print
    ; Вектор после вычитания
    (vec-sub init vector vector2 vector3)))
; Результат вывода в окно командной строки:
; {X:-1,2 Y:-1,2 Z:-2,2}

```
