# `vec-dot`

## 📦 Функция

```lisp
(vec-dot vector_1 vector_2)
```

## 📄 Описание

Вычисление скалярного произведения векторов.

## 📥 Аргументы

- `(vector3)` `vector_#` - вектор.

## 📈 Возвращает

`(double)` Скалярное произведение векторов.

## 🧾 Пример использования

```lisp
(let
  ; Создание векторов
  (
    (vector (vec 10 5 2))
    (vector2 (vec 3 10 0)))
  ; Вывод в командную строку
  (print
    ; Скалярное произведение векторов
    (vec-dot vector vector2)))

; Результат вывода в окно командной строки:
; 80.0

```
