# `vec-clamp`

## 📦 Функция

```lisp
(vec-clamp vector vector_min vector_max)
```

## 📄 Описание

Определение вектора расположенного в пределах заданного диапазона.

## 📥 Аргументы

- `(vector3)` `vector` - вектор;
- `(vector3)` `vector_min` - нижний предел диапазона;
- `(vector3)` `vector_max` - верхний предел диапазона.

## 📈 Возвращает

`(vector3)` Вектор в пределах заданного диапазона.

## 🧾 Пример использования

```lisp
(let
  ; Создание векторов
  (
    (min (vec))
    (max (vec 10))
    (init (vec -2 5 15)))
  ; Вывод в командную строку
  (print
    ; Вектор вписанный в заданный диапазон
    (vec-clamp init min max)))
; Результат вывода в окно командной строки:
; {X:0 Y:5 Z:10}

```
