# `vec-min`

## 📦 Функция

```lisp
(vec-min vector_1 vector_2)
```

## 📄 Описание

Создание вектора с наименьшими координатами.

## 📥 Аргументы

- `(vector3)` `vector_#` - вектор.

## 📈 Возвращает

`(vector3)` Вектор с наименьшими координатами.

## 🧾 Пример использования

```lisp
(let
  ; Создание векторов
  (
    (vector (vec 10 5 2))
    (vector2 (vec 3 10 0)))
  ; Вывод в командную строку
  (print
    ; Вектор с наименьшими координатами
    (vec-min vector vector2)))

; Результат вывода в окно командной строки:
; {X:3 Y:5 Z:0}

```
