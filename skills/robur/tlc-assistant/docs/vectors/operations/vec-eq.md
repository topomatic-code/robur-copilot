# `vec-eq`

## 📦 Функция

```lisp
(vec-eq vector_1 vector_2)
(vec-eq vector_1 vector_2 epsilon)
```

## 📄 Описание

Проверка равенства векторов.

## 📥 Аргументы

- `(vector3)` `vector_#` - сравниваемые векторы;
- `(double)` `epsilon` - допустимая погрешность.

## 📈 Возвращает

`(bool)` Результат проверки равенства векторов.

## 🧾 Пример использования

```lisp
(let
  ; Создание векторов
  (
    (vector (vec 1.0 0.0 0.0))
    (vector2 (vec 1.001 0.0 0.0)))
  ; Вывод в командную строку
  (print
    ; Разница координат векторов меньше или равна значению погрешности
    (vec-eq vector vector2 0.001))
  (print
    ; Разница координат векторов больше значения погрешности
    (vec-eq vector vector2 0.0001)))
; Результат вывода в окно командной строки:
; True
; False

```
