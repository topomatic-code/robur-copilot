# `vec-lerp`

## 📦 Функция

```lisp
(vec-lerp start end koef)
```

## 📄 Описание

Определение вектора расположенного на прямой заданной отрезком (линейная интерполяция).

## 📥 Аргументы

- `(vector3)` `start` - первая точка отрезка;
- `(vector3)` `end` - вторая точка отрезка;
- `(double)` `koef` - коэффициент длины отрезка.
           Расстояние до искомого вектора будет определено как произведение коэффициента на длину отрезка.

## 📈 Возвращает

`(vector3)` Результирующий вектор.

## 🧾 Пример использования

```lisp
(let
  ; Создание векторов
  (
    (start (vec))
    (end (vec 10 4 0)))
  ; Вывод в командную строку
  (print
    ; Вектор на прямой
    ; Коэффициент равен половине длины отрезка
    (vec-lerp start end 0.5))
  (print
    ; Коэффициент равен длине отрезка
    (vec-lerp start end 1.0))
  (print
    ; Коэффициент равен двойной отрицательной длине отрезка
    (vec-lerp start end -2.0)))
; Результат вывода в окно командной строки:
; {X:5 Y:2 Z:0}
; {X:10 Y:4 Z:0}
; {X:-20 Y:-8 Z:0}

```
