# `vec-max`

## 📦 Функция

```lisp
(vec-max vector_1 vector_2)
```

## 📄 Описание

Создание вектора с наибольшими координатами.

## 📥 Аргументы

- `(vector3)` `vector_#` - вектор.

## 📈 Возвращает

`(vector3)` Вектор с наибольшими координатами.

## 🧾 Пример использования

```lisp
(let
  ; Создание векторов
  (
    (vector (vec 10 5 2))
    (vector2 (vec 3 10 0)))
  ; Вывод в командную строку
  (print
    ; Вектор с наибольшими координатами
    (vec-max vector vector2)))

; Результат вывода в окно командной строки:
; {X:10 Y:10 Z:2}

```
