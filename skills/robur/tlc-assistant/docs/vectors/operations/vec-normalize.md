# `vec-normalize`

## 📦 Функция

```lisp
(vec-normalize vector)
```

## 📄 Описание

Нормализация вектора (приведение к единичному вектору).

## 📥 Аргументы

- `(vector3)` `vector` - вектор.

## 📈 Возвращает

`(vector3)` Нормализованный вектор.

## 🧾 Пример использования

```lisp
(let
  ; Создание векторов
  ((vector (vec 10 5 2)))
  ; Вывод в командную строку
  (print
    ; Нормализованный вектор
    (vec-normalize vector)))
; Результат вывода в окно командной строки:
; {X:0,880450906325624 Y:0,440225453162812 Z:0,176090181265125}

```
