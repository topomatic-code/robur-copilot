# `vec-reflect`

## 📦 Функция

```lisp
(vec-reflect vector normal)
```

## 📄 Описание

Вычисление зеркального отражения вектора.

## 📥 Аргументы

- `(vector3)` `vector` - вектор;
- `(vector3)` `normal` - нормаль плоскости отражения.

## 📈 Возвращает

`(vector3)` Зеркальное отражение вектора.

## 🧾 Пример использования

```lisp
(let
  ; Создание векторов
  (
    (vector (vec 10 5 2))
    (normal (vec 0 0 1)))
  ; Вывод в командную строку
  (print
    ; Зеркальное отражение вектора
    ; относительно плоскости заданной нормалью
    (vec-reflect vector normal)))

; Результат вывода в окно командной строки:
; {X:10 Y:5 Z:-2}

```
