# `import`

При работе с большими Tlc-скриптами конструкций удобно хранить код в разных файлах и подгружать их содержимое по мере необходимости в теле основного Tlc-скрипта.

Для импорта внешних Lisp-скриптов служит функция `import`.

В ходе импорта выполняется код скрипта, а возвращаемым значением будет результат выполнения последней инструкции.

Рассмотрим файл внешнего Lisp-скрипта `my_script.tlc`:

```lisp
; Инициализация глобальных переменных
; После импорта, можно обращаться к ним из основного TLC-скрипта
(setq
  my_dictionary (dict "key_1" "value_1" "key_2" "value_2")
  my_id "Custom ID")

; Определение компонента описанное ниже является
; последней выполняемой инструкцией в скрипте, поэтому
; именно её результат будет возвращаемым значением функции import.
; То есть импорт этого скрипта вернёт компонент "Балка" типа "SmdxElement".

; Определение компонента
(defcomponent "Балка" "SmdxElement"
  ; Свойство длины балки
  (defproperty length_property 1.0 "Длина"
    (v-property-double "m" 0 100))
  ; Определение геометрии балки
  (defgeometry
    (v-extrude
      (v-profile-p 0.01 0.2)
      (vec length_property 0))))
```

## 📦 Функция

```lisp
(import file_name)
```

## 📄 Описание

Импорт Lisp-скрипта.

## 📥 Аргументы

- `(string)` `file_name` - имя файла импортируемого Lisp-скрипта.

## 📈 Возвращает

`(dynamic)` Объект, возвращаемый последней инструкцией скрипта.

## 🧾 Пример использования

```lisp
; Это основной скрипт конструкции в который будет импортирован внешний LISP скрипт.
; Импорт внешнего LISP скрипта и сохранение возвращаемого значения.
; Из описания выше мы знаем, что скрипт вернёт компонент
(setq imported_component (import "my_script.tlc"))

; Определение компонента
(defcomponent "My Custom Construction" "SmdxElement"

  ; Определение геометрии
  (defgeometry
    (let
      ; Создание элемента ИМ
      ((im_element (defelement imported_component)))
      ; Вставка элемента ИМ
      (setelement "Вставка" im_element)))

  ; Вывод в окно командной строки
  ; значений переменных проинициализированных
  ; при импорте внешнего LISP скрипта
  (v-for (item my_dictionary)
    (print item))
  (print my_id))

; Результат вывода в окно командной строки:
; [key_1, value_1]
; [key_2, value_2]
; "Custom ID"
```
