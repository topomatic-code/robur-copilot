# `array-add`

## 📦 Функция

```lisp
(array-add array value_1 ... value_N)
```

## 📄 Описание

Добавление элементов в массив.

## 📥 Аргументы

- `(array)` `array` - массив, в который добавляются элементы;
- `(dynamic)` `value_#` - элемент массива.

## 📈 Возвращает

`(array)` Текущий массив.

## 🧾 Пример использования

```lisp
(let
  ; Создаём массив и присваиваем его переменной
  ((my_array (array "Pi" "e")))
  ; Добавляем элементы в массив
  (array-add my_array "Y" "F"))
```
