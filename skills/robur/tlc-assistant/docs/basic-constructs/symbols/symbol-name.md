# `symbol-name`

## 📦 Функция

```lisp
(symbol-name symbol)
```

## 📄 Описание

Получение имени символа.

## 📥 Аргументы

- `(symbol)` `symbol` - символ.

## 📈 Возвращает

`(string)` Имя символа.

## 🧾 Пример использования

```lisp
(let
  ; Создание символа
  ((sym (make-symbol "custom_tag")))
  ; Вывод имени символа в командную строку
  (print (symbol-name sym)))

; Результат вывода в командную строку:
; "custom_tag"
```
