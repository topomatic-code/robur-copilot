# `intern`

## 📦 Функция

```lisp
(intern name)
```

## 📄 Описание

Создание нового или возвращение уже существующего символа с указанным именем.

## 📥 Аргументы

- `(string)` `name` - имя символа.

## 📈 Возвращает

`(symbol)` Созданный символ.

## 🧾 Пример использования

```lisp
(intern "custom_tag")
```
