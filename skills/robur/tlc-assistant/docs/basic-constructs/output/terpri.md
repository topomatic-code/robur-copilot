# `terpri`

## 📦 Функция

```lisp
(terpri)
```

## 📄 Описание

Вывод пустой строки в окне командной строки.

## 📈 Возвращает

`(string)` Строка.

## 🧾 Пример использования

```lisp
(print "Строка_1")
(terpri)
(print "Строка_2")
(terpri)
(print "Строка_3")

; Результат вывода в окно командной строки:
; "Строка_1"
;
; "Строка_2"
;
; "Строка_3"
```
