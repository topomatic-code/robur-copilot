# `print`

## 📦 Функция

```lisp
(print string)
```

## 📄 Описание

Вывод символов заданной строки в кавычках в новой строке окна командной строки.

## 📥 Аргументы

- `(string)` `string` - строка, выводимая в окно командной строки.

## 📈 Возвращает

`(string)` Переданная строка.

## 🧾 Пример использования

```lisp
(print "Строка_1")
(print "Строка_2")
(print "Строка_3")

; Результат вывода в окно командной строки:
; "Строка_1"
; "Строка_2"
; "Строка_3"
```
