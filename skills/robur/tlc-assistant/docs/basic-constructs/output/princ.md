# `princ`

## 📦 Функция

```lisp
(princ string)
```

## 📄 Описание

Вывод символов заданной строки без кавычек в текущем положении курсора окна командной строки.

## 📥 Аргументы

- `(string)` `string` - строка, выводимая в окно командной строки.

## 📈 Возвращает

`(string)` Переданная строка.

## 🧾 Пример использования

```lisp
(princ "Строка_1")
(princ "Строка_2")
(princ "Строка_3")

; Результат вывода в окно командной строки:
; Строка_1Строка_2Строка_3
```
