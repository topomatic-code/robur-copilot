# `prin1`

## 📦 Функция

```lisp
(prin1 string)
```

## 📄 Описание

Вывод символов заданной строки в кавычках в текущем положении курсора окна командной строки.

## 📥 Аргументы

- `(string)` `string` - строка, выводимая в окно командной строки.

## 📈 Возвращает

`(string)` Переданная строка.

## 🧾 Пример использования

```lisp
(prin1 "Строка_1")
(prin1 "Строка_2")
(prin1 "Строка_3")

; Результат вывода в окно командной строки:
; "Строка_1""Строка_2""Строка_3"
```
