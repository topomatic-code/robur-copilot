# `enum-current`

## 📦 Функция

```lisp
(enum-current enumerator)
```

## 📄 Описание

Получение объекта коллекции, на который указывает перечислитель.

## 📥 Аргументы

- `(iterator)` `enumerator` - итератор коллекции.

## 📈 Возвращает

`(dynamic)` Элемент коллекции.

## 🧾 Пример использования

```lisp
(let
  ; Объявление переменных
  (dic enumerator)
  (setq
    ; Создание словаря
    dic (dict "key_1" "value_1" "key_2" "value_2")
    ; Получение перечислителя
    enumerator (enum-get dic))
  ; Пока перечислитель способен переместить указатель
  ; на текущий объект коллекции, выводим в окно командной строки
  ; значение объекта коллекции на которую указывает перечислитель
  (while (enum-next enumerator)
    (print
      (enum-current enumerator))))

; Результат вывода в окно командной строки:
; [key_1, value_1]
; [key_2, value_2]
```
