# `reverse`

## 📦 Функция

```lisp
(reverse collection)
```

## 📄 Описание

Получение коллекции с обратным порядком следования элементов.

## 📥 Аргументы

- `(dynamic)` `collection` - коллекция объектов.

## 📈 Возвращает

`(iterator)` Набор элементов в обратном порядке.

## 🧾 Пример использования

```lisp
(let
  ; Создание коллекции
  ((dic (dict "key_1" "value_1" "key_2" "value_2")))
  ; Объявление итерации
  (v-for
    ; Объявление переменной для текущего элемента итерации
    ; в развёрнутой коллекции
    (item (reverse dic))
    ; Вывод значения текущего объекта итерации в окно командной строки
    (print item)))

; Результат вывода в окно командной строки:
; [key_2, value_2]
; [key_1, value_1]
```
