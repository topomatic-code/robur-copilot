# `enum-reset`

## 📦 Функция

```lisp
(enum-reset enumerator)
```

## 📄 Описание

Сброс положения указателя перечислителя на текущий объект коллекции.

## 📥 Аргументы

- `(iterator)` `enumerator` - итератор коллекции.

## 📈 Возвращает

`(bool)` Истина/ложь.

## 🧾 Пример использования

```lisp
(let
  ; Объявление переменных
  (dic enumerator count)
  (setq
    ; Создание словаря
    dic (dict "key_1" "value_1" "key_2" "value_2")
    ; Получение перечислителя
    enumerator (enum-get dic)
    ; Счётчик
    count 0)
  ; Пока перечислитель способен переместить указатель
  ; на текущий объект коллекции, увеличиваем счётчик на один
  (while (enum-next enumerator)
    (setq count (+ count 1)))
  ; Сброс положения указателя перечислителя на текущий объект коллекции
  (enum-reset enumerator))
```
