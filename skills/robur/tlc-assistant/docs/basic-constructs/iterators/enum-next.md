# `enum-next`

## 📦 Функция

```lisp
(enum-next enumerator)
```

## 📄 Описание

Перемещение указателя на текущий элемент в коллекции на следующую позицию.

## 📥 Аргументы

- `(iterator)` `enumerator` - итератор коллекции.

## 📈 Возвращает

`(bool)` Истина/ложь.

## 🧾 Пример использования

```lisp
(let
  ; Объявление переменных
  (dic enumerator)
  (setq
    ; Создание словаря
    dic (dict "key_1" "value_1" "key_2" "value_2")
    ; Получение перечислителя словаря
    enumerator (enum-get dic))
  ; Перемещение указателя на текущий элемент
  ; в коллекции на следующую позицию
  (enum-next enumerator))
```
