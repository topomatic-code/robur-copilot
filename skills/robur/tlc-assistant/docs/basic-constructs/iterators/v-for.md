# `v-for`

## 📦 Функция

```lisp
(v-for (item collection) func_1 func_2 ... func_N)
```

## 📄 Описание

Цикл итераций по элементам коллекции.

## 📥 Аргументы

- `(variable)` `item` - временная переменная, которая будет указывать на объект текущей итерации;
- `(dynamic)` `collection` - коллекция объектов;
- `(func)` `func_#` - операции, производимые в текущей итерации.

## 📈 Возвращает

`nil`.

## 🧾 Пример использования

```lisp
(let
  ; Создание коллекции
  ((dic (dict "key_1" "value_1" "key_2" "value_2")))
  ; Объявление итерации
  (v-for
    ; Объявление переменной для текущего элемента итерации
    (item dic)
    ; Вывод значения текущего объекта итерации в окно командной строки
    (print item)))

; Результат вывода в окно командной строки:
; [key_1, value_1]
; [key_2, value_2]
```
