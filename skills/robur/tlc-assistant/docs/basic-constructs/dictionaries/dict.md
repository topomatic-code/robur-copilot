# `dict`

## 📦 Функция

```lisp
(dict key_1 value_1 ... key_N value_N)
```

## 📄 Описание

Создание словаря.

## 📥 Аргументы

- `(dynamic)` `key_#` - ключ элемента словаря;
- `(dynamic)` `value_#` - значение элемента словаря.

## 📈 Возвращает

`(map)` Созданный словарь.

## 💬 Примечания

Количество аргументов `value` должно соответствовать количеству аргументов `key`.

## 🧾 Пример использования

```lisp
(dict
  "Value1" "Значение1"
  "Value2" 0.2
  "Value3" (vec 3)
  "Value4" "Значение4")
```
