# `dict-remove`

## 📦 Функция

```lisp
(dict-remove dictionary key)
```

## 📄 Описание

Удаление записи словаря по ключу.

## 📥 Аргументы

- `(map)` `dictionary` - словарь, в котором производится поиск;
- `(dynamic)` `key` - ключ искомой записи словаря.

## 📈 Возвращает

`(bool)` `true` или `null`, если запись не найдена.

## 🧾 Пример использования

```lisp
; Создаём словарь и присваиваем его переменной
(setq constants
  (dict
    "Pi" 3.14159265358979323846264338327950288
    "e" 2.71828182845904523536028747135266250
    "Y" 0.57721566490153286060651209008240243))
; Удаляем запись словаря с ключом "Pi"
(dict-remove constants "Pi")
```
