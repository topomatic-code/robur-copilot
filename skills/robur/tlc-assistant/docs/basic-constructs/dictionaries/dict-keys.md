# `dict-keys`

## 📦 Функция

```lisp
(dict-keys dictionary)
```

## 📄 Описание

Получение коллекции ключей словаря.

## 📥 Аргументы

- `(map)` `dictionary` - словарь, в котором производится поиск.

## 📈 Возвращает

`(list)` Коллекция ключей.

## 🧾 Пример использования

```lisp
; Создаём словарь и присваиваем его переменной
(setq constants
  (dict
    "Pi" 3.14159265358979323846264338327950288
    "e" 2.71828182845904523536028747135266250
    "Y" 0.57721566490153286060651209008240243))
; Получаем коллекцию ключей словаря
(dict-keys constants)
```
