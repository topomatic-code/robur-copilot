# `dict-values`

## 📦 Функция

```lisp
(dict-values dictionary)
```

## 📄 Описание

Получение коллекции значений словаря.

## 📥 Аргументы

- `(map)` `dictionary` - словарь, в котором производится поиск.

## 📈 Возвращает

`(list)` Коллекция значений.

## 🧾 Пример использования

```lisp
; Создаём словарь и присваиваем его переменной
(setq constants
  (dict
    "Pi" 3.14159265358979323846264338327950288
    "e" 2.71828182845904523536028747135266250
    "Y" 0.57721566490153286060651209008240243))
; Получаем коллекцию значений словаря
(dict-values constants)
```
