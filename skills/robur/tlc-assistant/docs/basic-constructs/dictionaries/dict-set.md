# `dict-set`

## 📦 Функция

```lisp
(dict-set dictionary key value)
```

## 📄 Описание

Присваивание значения записи словаря с указанным ключом.

## 📥 Аргументы

- `(map)` `dictionary` - словарь, в котором производится поиск;
- `(dynamic)` `key` - ключ искомой записи словаря;
- `(dynamic)` `value` - новое значение.

## 📈 Возвращает

`nil`.

## 🧾 Пример использования

```lisp
; Создаём словарь и присваиваем его переменной
(setq constants
  (dict
    "Pi" 3.141
    "e" 2.71828182845904523536028747135266250
    "Y" 0.57721566490153286060651209008240243))
; Присваиваем новое значение записи словаря с ключом "Pi"
(dict-set constants "Pi" 3.14159265358979323846264338327950288)
```
