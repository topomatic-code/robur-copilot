# `v-profile-g`

## 📦 Функция

```lisp
(v-profile-g thickness width)
(v-profile-g thickness width height)
```

## 📄 Описание

Создание Г-образного профиля (уголок).

## 📥 Аргументы

- `(double)` `thickness` - толщина стенки;
- `(double)` `width` - ширина;
- `(double)` `height` - высота (по умолчанию равна значению аргумента width).

## 📈 Возвращает

`(profile)` Профиль.

## 💬 Примечания

```text
=== Схема определения точек профиля ===
Профиль задан на плоскости XY, с началом координат O(0;0).
w2 = width / 2;  h2 = height / 2;  t = thickness.
                         Y+
                         ↑
                         │
                         │
 p0=p11      p9=p10      │
 (-w2;+h2)   (-w2+t;+h2) │
       ●────────●        │
       │        │        │
       │        │        │
       │        │        │
       │        │        │
       │        │        │
──────────────────────O(0;0)────────────────────────────→ X+
       │        │        │
       │        ●─────────────────────────● p5=p6
       │      p7=p8      │                │ (+w2;-h2+t)
       │  (-w2+t;-h2+t)  │                │
       │                 │                │
       ●──────────────────────────────────●
   p1=p2                 │              p3=p4
 (-w2;-h2)               │              (+w2;-h2)
                         │
                         │
                         │
Обход контура против ЧС: p0 → p1 → p2 → p3 → p4 → p5 → p6 → p7 → p8 → p9 → p10 → p11.
Контур разомкнут (closed = false).
```

## 🧾 Пример использования

Создание Г-образного профиля с толщиной стенки 0,05 м, шириной и высотой 2 м, затем его выдавливание на 0,1 м:

```lisp
; Объявление блока геометрии
(defgeometry
  ; Создание 3D-тела путём выдавливания профиля
  (v-extrude
    ; Определение Г-образного профиля со стенками одинаковой ширины
    (v-profile-g 0.05 2.0)
    ; Вектор выдавливания
    (vec 0.0 0.0 0.1)))
```

Создание Г-образного профиля с толщиной стенки 0,05 м, шириной 2 м и высотой 1 м, затем его выдавливание на 0,1 м:

```lisp
; Объявление блока геометрии
(defgeometry
  ; Создание 3D-тела путём выдавливания профиля
  (v-extrude
    ; Определение Г-образного профиля со стенками разной ширины
    (v-profile-g 0.05 2.0 1.0)
    ; Вектор выдавливания
    (vec 0.0 0.0 0.1)))
```
