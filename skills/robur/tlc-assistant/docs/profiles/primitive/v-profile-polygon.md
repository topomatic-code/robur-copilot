# `v-profile-polygon`

## 📦 Функция

```lisp
(v-profile-polygon quantity radius)
```

## 📄 Описание

Создание вписанного многоугольного профиля.

## 📥 Аргументы

- `(integer)` `quantity` - количество углов;
- `(double)` `radius` - радиус окружности.

## 📈 Возвращает

`(profile)` Профиль.

## 💬 Примечания

```text
=== Схема определения точек профиля ===
Профиль задан на плоскости XY, с началом координат O(0.0;0.0).
Строится многоугольник с n вершинами.
Точки идут по углу angle = i * delta, i=0..n-1. Где delta = pi * 2 / quantity.
               Y+
               ↑
               │
               │
               │     p1 = p1'
            ●──────●
         /     │     \
        /      │      \
       /       │       \  p0 = p0'
──────●─────O(0;0)──────●──────→ X+
       \       │       /
        \      │      /
         \     │     /
           ●───────●  pn-1 = pn-1'
               │
               │
               │
for i = 0..n-1: p[i] = (r*cos(angle); r*sin(angle)).
angle == 0 : p0(+r;0.0).
Обход контура против ЧС: p0 → p1 → p1' → ... → pn-1 → pn-1' → p0'.
Для корректной обработки граней в каждой вершине точки дублируются: p1 = p1', pn-1 = pn-1' и т.д.
Первая (p0) и последняя (p0') точки совпадают.
Контур разомкнут (closed = false).
```

## 🧾 Пример использования

```lisp
; Объявление блока геометрии
(defgeometry
  ; Создание 3D-тела путём выдавливания профиля
  (v-extrude
    ; Определение восьмиугольного профиля
    (v-profile-polygon 8 1.0)
    ; Вектор выдавливания
    (vec 0.0 0.0 0.1)))
```
