# `v-profile-arc`

## 📦 Функция

```lisp
(v-profile-arc radius angle span)
```

## 📄 Описание

Создание профиля сегмента окружности.

## 📥 Аргументы

- `(double)` `radius` - радиус дуги;
- `(double)` `angle` - угол начала дуги;
- `(double)` `span` - градусная мера дуги.

## 📈 Возвращает

`(profile)` Профиль.

## 🧾 Пример использования

```lisp
; Объявление блока геометрии
(defgeometry
  ; Создание 3D-тела путём выдавливания профиля
  (v-extrude
    ; Определение профиля сегмента окружности
    (v-profile-arc 1.0 0 120)
    ; Вектор выдавливания
    (vec 0.0 0.0 0.1)))
```
