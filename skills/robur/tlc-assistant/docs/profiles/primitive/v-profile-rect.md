# `v-profile-rect`

## 📦 Функция

```lisp
(v-profile-rect width)        ; Квадратный профиль
(v-profile-rect width height) ; Прямоугольный профиль
```

## 📄 Описание

Создание прямоугольного профиля.

## 📥 Аргументы

- `(double)` `width` - ширина;
- `(double)` `height` - высота (по умолчанию равно значению аргумента width).

## 📈 Возвращает

`(profile)` Профиль.

## 💬 Примечания

```text
=== Схема определения точек профиля ===
Профиль задан на плоскости XY, с началом координат O(0.0;0.0).
w2 = width / 2; h2 = height / 2.
              Y+
              ↑
              │
   p1=p2      │      p0=p7
(-w2;+h2)     │   (+w2;+h2)
       ●──────┼──────●
       │      │      │
       │      │      │
       │      O      │
  ─────│────(0;0)────│──────→ X+
       │      │      │
       │      │      │
       ●──────┼──────●
(-w2;-h2)     │   (+w2;-h2)
   p3=p4      │      p5=p6
Обход контура против ЧС: p0 → p1 → p2 → p3 → p4 → p5 → p6 → p7.
Контур разомкнут (closed = false).
```

## 🧾 Пример использования

Создание квадратного профиля со стороной 2 м и его выдавливание на 0,1 м:

```lisp
; Объявление блока геометрии
(defgeometry
  ; Создание 3D-тела путём выдавливания профиля
  (v-extrude
    ; Определение квадратного профиля
    (v-profile-rect 2.0)
    ; Вектор выдавливания
    (vec 0.0 0.0 0.1)))
```

Создание прямоугольного профиля размером 2 × 1 м и его выдавливание на 0,1 м:

```lisp
; Объявление блока геометрии
(defgeometry
  ; Создание 3D-тела путём выдавливания профиля
  (v-extrude
    ; Определение прямоугольного профиля
    (v-profile-rect 2.0 1.0)
    ; Вектор выдавливания
    (vec 0.0 0.0 0.1)))
```
