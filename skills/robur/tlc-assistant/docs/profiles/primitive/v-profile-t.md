# `v-profile-t`

## 📦 Функция

```lisp
(v-profile-t thickness width)
(v-profile-t thickness width height)
```

## 📄 Описание

Создание Т-образного профиля (тавр).

## 📥 Аргументы

- `(double)` `thickness` - толщина стенки;
- `(double)` `width` - ширина;
- `(double)` `height` - высота (по умолчанию равна значению аргумента width).

## 📈 Возвращает

`(profile)` Профиль.

## 💬 Примечания

```text
=== Схема определения точек профиля ===
Профиль задан на плоскости XY, с началом координат O(0;0).
w2 = width / 2;  h2 = height / 2;  t = thickness;  t2 = thickness / 2.
                         Y+
                         ↑
                         │
                         │
             p0=p15      │    p13=p14
             (-t2;+h2)   │    (+t2;+h2)
                    ●────│────●
                    │    │    │
                    │    │    │
                    │    │    │
                    │    │    │
                    │    │    │
──────────────────────O(0;0)────────────────────────────→ X+
                    │    │    │
     p3=p4          │    │    │          p9=p10
   (-w2;-h2+t)      │    │    │        (+w2;-h2+t)
       ●────────────●    │    ●────────────●
       │          p1=p2  │  p11=p12        │
       │     (-t2;-h2+t) │ (+t2;-h2+t)     │
       │                 │                 │
       ●─────────────────│─────────────────●
     p5=p6               │               p7=p8
   (-w2;-h2)             │             (+w2;-h2)
                         │
Обход контура против ЧС:
p0 → p1 → p2 → p3 → p4 → p5 → p6 → p7 → p8 → p9 → p10 → p11 → p12 → p13 → p14 → p15.
Контур разомкнут (closed = false).
```

## 🧾 Пример использования

Создание Т-образного профиля с толщиной стенки 0,05 м, шириной и высотой 2 м, затем его выдавливание на 0,1 м:

```lisp
; Объявление блока геометрии
(defgeometry
  ; Создание 3D-тела путём выдавливания профиля
  (v-extrude
    ; Определение T-образного профиля со стенками одинаковой ширины
    (v-profile-t 0.05 2.0)
    ; Вектор выдавливания
    (vec 0.0 0.0 0.1)))
```

Создание Т-образного профиля с толщиной стенки 0,05 м, шириной 2 м и высотой 1 м, затем его выдавливание на 0,1 м:

```lisp
; Объявление блока геометрии
(defgeometry
  ; Создание 3D-тела путём выдавливания профиля
  (v-extrude
    ; Определение T-образного профиля со стенками разной ширины
    (v-profile-t 0.05 2.0 1.0)
    ; Вектор выдавливания
    (vec 0.0 0.0 0.1)))
```
