# `v-profile-loft`

## 📦 Функция

```lisp
(v-profile-loft (cons 0.0 profile_1) (cons u_2 profile_2) ... (cons 1.0 profile_N))
(v-profile-loft transition_func (cons 0.0 profile_1) (cons u_2 profile_2) ... (cons 1.0 profile_N))
```

## 📄 Описание

Создание изменяемого вдоль траектории выдавливания профиля.

## 📥 Аргументы

- `(cons)` `cons_#` - ячейка вида пары «u-профиль»;
- `(lambda)` `transition_func` - фунция перехода между профилями.

## 📈 Возвращает

`(profile)` Профиль.

## 💬 Примечания

Количество контуров в профилях должно совпадать.

В отличие от функции v-profile-loft-exact количество точек соответствующих контуров сечений профилей может отличаться.

Значение u задает положение профиля на траектории выдавливания и может принимать значения от 0.0 до 1.0,
где 0.0 соответствует положению в начале траектории, а 1.0 в конце.

Должно быть задано как минимум 2 профиля: для u = 0.0 и u = 1.0.

Для каждого набора соответствующих контуров профилей определяется общая выборка u_sec сечений.

Значения в u_sec находятся в пределах от 0.0 до 1.0, где 0.0 соответсвует положению начала контура сечения, а 1.0 концу.

Общая выборка u_sec гарантирует, что все вершины переданных пользователем профилей, будут учтены в результирующем теле.

При расчете профиля для произвольного u, выбираются два значения: u0 и u1, где u0 <= u <= u1.

По значениям u_sec формируются 2 набора точек для соответствующих контуров u0 и u1 профилей. Таким образом, если количество точек в соответствующих
контурах профилей отличается, то в выборках их количество будет совпадать, что позволит корректно выполнить триангуляцию боковых граней результирющего тела.

Далее из выборок контуров профилей, последовательно выбираются пары точек p0 (из выборки для профиля u0) и p1 (из выборки для профиля u1).

Точка p результирующиего профиля u определяется при помощи линейной интерполляции lerp(p0, p1, t).
Где параметр t - коэффициент интерполляции.

Если transition_func не задана, то рассчитывается как t = (u - u0) / (u1 - u0).

Если transition_func задана, то t = transition_func(u, t). То есть после стандартного расчета t модифицируется возвращаемым значением пользовательской функции transition_func, позволяя задавать нелинейный переход между профилями.

Важно учесть, что у соответствующих контуров профилей начальная точка контура может располагаться где угодно, поэтому одна и та же 2d-позиция для u_sec может сильно отличаться для пары контуров, что может привести к нежелательным эффектам при вытягивании тела (скручиванию и т.д.). Это означает, что необходимо поддерживать соответсвие топологий соответствующих контуров профилей.

## 🧾 Пример использования

```lisp
(defcomponent "Loft из прямоугольника в круг" "SmdxElement"
  (defgeometry
    (v-extrude
      (v-profile-loft (cons 0.0 (v-profile-rect 4.0 2.5))
                      (cons 1.0 (v-profile-rotate (v-profile-round 1.5) 35))) ; rotate для избежания скручивания тела
      (vec 3.0 0.0 0.0))))
```
