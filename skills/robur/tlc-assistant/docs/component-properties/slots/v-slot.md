# `v-slot`

## 📦 Функция

```lisp
(v-slot id default_value caption smdx_type)
```

## 📄 Описание

Определение свойства типа слот (коллекция элементов информационной модели).

## 📥 Аргументы

- `(string)` `id` - идентификатор свойства;
- `(dynamic)` `default_value` - значение свойства по умолчанию;
- `(string)` `caption` - заголовок свойства;
- `(string)` `smdx_type` - тип элемента информационной модели.

## 📈 Возвращает

`(property)` Свойство.

## 🧾 Пример использования

```lisp
(v-slot
  "points_property" ; Идентификатор свойства
  nil               ; Значение по умолчанию
  "Точки"           ; Заголовок в инспекторе свойств
  "SmdxPoint")      ; Тип элемента информационной модели

```
