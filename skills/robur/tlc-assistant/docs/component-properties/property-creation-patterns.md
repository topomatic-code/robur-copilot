# Применение `defproperty`, `setproperty` и `v-property`

Функции `defproperty` и `setproperty` являются упрощённым способом создания изменяемых и неизменяемых свойств соответственно.

В подавляющем большинстве случаев рекомендуется пользоваться именно этими функциями.

Например, использование функции `defproperty` и функции `v-property` со значением `t` аргумента `changable` приведут к одинаковому результату.

Принципиальное различие заключается в аргументах:

- `variable` у функций `defproperty` и `setproperty`;
- `id` у функции `v-property`.

В первом случае явно указывается переменная в качестве аргумента, во втором указывается строковый идентификатор.

Во втором случае для указанного идентификатора неявно создаётся переменная, которую в дальнейшем можно использовать для доступа к свойству.

Функцию `v-property` удобно использовать с типом свойства `v-property-enum`, когда у одного свойства могут быть различные наборы значений в зависимости от состояния конструкции.

Например, для разного материала изделия может различаться допускаемый перечень размеров. Если просто менять перечень в enum-свойстве, можно столкнуться с проблемой, когда в инспекторе свойств будет указано, что значение свойства не задано.

Это связано с тем, что у свойства уже задано какое-то значение, и его может не оказаться среди нового перечня.

В этом случае, чтобы не создавать для каждого перечня отдельное свойство, следует воспользоваться функцией `v-property` и созданием символа. Так переменная свойства будет оставаться одинаковой, а идентификатор свойства для каждого перечня будет уникальным.

## Пример

В примере определяется enum-свойство `Размер`, в котором используются различные перечни допустимых значений в зависимости от выбранного материала конструкции.

Сначала определяются словари допустимых материалов и размеров, затем вспомогательные функции:

- `gen-size-property-tag` - возвращает уникальный символ для соответствующего материала конструкции;
- `get-sizes` - возвращает словарь размеров для соответствующего материала конструкции;
- `get-first-dict-element` - возвращает первый элемент словаря, который используется в качестве значения по умолчанию для enum-свойства.

```lisp
; Описание различных перечней размеров для разных материалов
(setq materials (dict "ЖБ"     "ЖБ"
                      "Дерево" "Дерево")
      wood_sizes (dict "0.5"  "0.5"
                       "1.0"  "1.0"
                       "1.25" "1.25"
                       "2.5"  "2.5")
      concrete_sizes (dict  "5.0"  "5.0"
                           "10.0" "10.0"
                           "20.0" "20.0"))

; Генерация символа для свойства размера в зависимости от материала
(defun gen-size-property-tag (material)
  (let (m)
    (setq m (cond
              ((eql material "ЖБ") "c")          ;concrete
              ((eql material "Дерево") "w")      ;wood
              (t "u")))                          ;unknown
  (make-symbol (format "size_property_{0}" m))))

; Получение перечня размеров по материалу
(defun get-sizes (material)
  (let (types)
    (setq types (cond
                  ((eql material "ЖБ") concrete_sizes) ;concrete
                  ((eql material "Дерево") wood_sizes) ;wood
                  (t (dict))))))                       ;unknown

; Получение первого элемента словаря
(defun get-first-dict-element (dic)
  (let
    (enum first)
    (setq enum (enum-get (dict-keys dic)))
    (enum-next enum)
    (setq first (enum-current enum))
    (enum-reset enum)
    first))

; Определение конструкции
(defcomponent "My Custom Construction" "SmdxElement"
  ; Определение блока геометрии (для примера)
  (defgeometry
    (v-extrude (v-profile-round 1) (vec 0 0 3)))
  ; Определение свойства материала
  (defproperty material_property "ЖБ" "Материал" (v-property-enum materials))
  ; Генерируем уникальный символ, который будет использоваться в качестве переменной для доступа к свойству размера
  (setq size_property_tag (gen-size-property-tag material_property))
  (let
    ; Определяем перечень размеров соответствующий материалу
    ((selected_sizes (get-sizes material_property)))
    ; Определение свойства размера
    (v-property
      ; Изменяемое значение свойства
      t
      ; Имя символа в качестве идентификатора
      (symbol-name size_property_tag)
      ; Первый элемент перечня как значение по умолчанию
      (get-first-dict-element selected_sizes)
      ; Заголовок свойства
      "Размер"
      ; Перечень размеров
      (v-property-enum selected_sizes))))
```
