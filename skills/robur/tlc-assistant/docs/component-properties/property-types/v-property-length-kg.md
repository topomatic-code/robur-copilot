# `v-property-length-kg`

## 📦 Функция

```lisp
(v-property-length-kg)
(v-property-length-kg min_limit)
(v-property-length-kg min_limit max_limit)
```

## 📄 Описание

Создание типа свойства: вещественное число с единицами измерения в килограммах.

## 📥 Аргументы

- `(double)` `min_limit` - минимальное допустимое значение;
- `(double)` `max_limit` - максимальное допустимое значение.

## 📈 Возвращает

`(property_type)` Тип свойства.

## 🧾 Пример использования

```lisp
(v-property-length-kg 0 100)

```
