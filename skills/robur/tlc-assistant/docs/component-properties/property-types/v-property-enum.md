# `v-property-enum`

## 📦 Функция

```lisp
(v-property-enum items)
```

## 📄 Описание

Создание типа свойства: перечисление.

## 📥 Аргументы

- `(dynamic)` `items` - Элементы перечисления. Если элемент пара ключ/значение, то ключ пары устанавливается в качестве
значения элемента, а значение ключа является описанием элемента. Может быть типа перечисление строк или пар ключ/значение (строка/строка) или словарь.

## 📈 Возвращает

`(property_type)` Тип свойства.

## 🧾 Пример использования

```lisp
(v-property-enum
  "Value1" "Значение1"
  "Value2" "Значение2"
  "Value3" "Значение3"
  "Value4" "Значение4")
; или
(setq EnumValues
  (dict
    "Value1" "Значение1"
    "Value2" "Значение2"
    "Value3" "Значение3"
    "Value4" "Значение4"))
(v-property-enum EnumValues)

```
