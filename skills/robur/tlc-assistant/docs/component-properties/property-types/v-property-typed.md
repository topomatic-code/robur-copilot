# `v-property-typed`

## 📦 Функция

```lisp
(v-property-typed type)
```

## 📄 Описание

Создание типа свойства: объект информационной модели.

## 📥 Аргументы

- `(string)` `type` - тип объекта информационной модели.

## 📈 Возвращает

`(property_type)` Тип свойства.

## 🧾 Пример использования

```lisp
; Свойство с таким типом определяет, что при выборе объекта в инспекторе свойств,
; пользователю будет доступны только те объекты которые наследуют тип "SmdxElement"
(v-property-typed "SmdxElement")

```
