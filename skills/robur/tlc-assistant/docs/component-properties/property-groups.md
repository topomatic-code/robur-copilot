# Группировка свойств

Для упорядочивания свойств в компонентах удобно объединять их в группы по общему признаку.

Например, в группу `Вид` можно поместить свойства `Цвет` и `Форма`, а в группу `Размер` - свойства `Ширина` и `Высота`.

Группа создаётся автоматически, если имя свойства содержит имя группы, отделённое символом `|`.

В общем виде создание группы свойств сводится к именованию свойств по шаблону:

```text
Имя группы|Имя свойства
```

Группы свойств могут иметь неограниченное количество уровней вложенности. Другими словами, группы свойств могут содержать в себе другие группы свойств.

Для этого в имени свойства нужно указать необходимое количество уровней:

```text
Имя группы|Имя подгруппы 1|…|Имя подгруппы N|Имя свойства
```

Свойства компонента отображаются в инспекторе свойств в том порядке, в котором они были объявлены в компоненте.

Группы позволяют не соблюдать определённый порядок объявления свойств в теле компонента и помогают сортировать свойства в определённом порядке.

## Пример

```lisp
; Объявление коллекции свойств
(v-properties
  ; Для свойства "Цвет" будет создана группа "Вид"
  ; в соответствии с шаблоном именования свойства
  (defproperty
    color_property
    "red" "Вид|Цвет"
    (v-property-enum
      (dict
        "red"   "Красный"
        "green" "Зелёный"
        "blue"  "Синий")))
  ; Для свойства "Ширина" будет создана группа "Размеры"
  ; В группе "Размеры" будет создана подгруппа "Деталь 1"
  (defproperty
    detail_one_width_property
    1.0 "Размер|Деталь 1|Ширина"
    (v-property-length-m))
  ; Так как группа "Размеры" уже существует,
  ; то в него добавится подгруппа "Деталь 2"
  (defproperty
    detail_two_width_property
    1.0 "Размер|Деталь 2|Ширина"
    (v-property-length-m))
  ; Подгруппа "Деталь 1" уже существует
  ; в группе "Размеры", поэтому свойство будет
  ; расположено в уже существующей подгруппе
  (defproperty
    detail_one_height_property
    1.0 "Размер|Деталь 1|Высота"
    (v-property-length-m))
  ; Подгруппа "Деталь 2" уже существует
  ; в группе "Размеры", поэтому свойство будет
  ; расположено в уже существующей подгруппе
  (defproperty
    detail_two_height_property
    1.0 "Размер|Деталь 2|Высота"
    (v-property-length-m))
  ; Группа "Вид" уже существует,
  ; поэтому свойство "Форма" будет
  ; расположено в уже существующей группе.
  ; Несмотря на то, что это свойство объявлено последним,
  ; в инспекторе свойств оно будет расположено выше группы
  ; "Размеры", так как группа "Вид" была создана раньше
  (defproperty
    shape_property
    "parallelepiped" "Вид|Форма"
    (v-property-enum
      (dict
        "parallelepiped" "Параллелепипед"
        "cylinder"       "Цилиндр"))))
```
