# `v-curve-polyline`

## 📦 Функция

```lisp
(v-curve-polyline pos_1 pos_2 ... pos_N)
(v-curve-polyline positions)
```

## 📄 Описание

Создание кривой из набора точек.

## 📥 Аргументы

- `(vector3)` `pos_#` - точка кривой;
- `(dynamic)` `positions` - список или массив точек кривой.

## 📈 Возвращает

`(curve)` Кривая.

## 🧾 Пример использования

Создание полилинии из четырёх точек, переданных отдельными аргументами:

```lisp
; Создание кривой из набора точек
(v-curve-polyline
  (vec 0.0 0.0 0.0)
  (vec 2.0 0.0 0.0)
  (vec 4.0 2.0 0.0)
  (vec 6.0 3.0 1.0))
```

Создание той же полилинии из списка из четырёх точек:

```lisp
; Создание кривой из списка точек
(let (positions)
  (setq positions
    (list
      (vec 0.0 0.0 0.0)
      (vec 2.0 0.0 0.0)
      (vec 4.0 2.0 0.0)
      (vec 6.0 3.0 1.0)))
  (v-curve-polyline positions))
```
