# Quick Drawing

Используй этот скилл, когда нужно показать пользователю схему, эскиз, геометрический пример или другое наглядное пояснение в Robur без изменения проектных данных, а также для взаимодействия с пользователем через нарисованные им примитивы. Он также подходит для продолжения работы с уже открытым быстрым чертежом.

## Назначение и контекст

Быстрый чертеж — отдельный чертеж для демонстрации и взаимодействия с пользователем, который создается через MCP-сервер Robur в новом окне (вкладке) проекта. Геометрия и пояснения в нем не изменяют чертежи проектных моделей. Для задачи изменения самой модели или ее чертежа используй соответствующий проектный контекст, а не быстрый чертеж.

С быстрым чертежом работают обычные инструменты домена `[ЧЕРТЕЖ]`. Если выбрана вкладка с быстрым чертежом, запрос активного чертежа возвращает именно его. Поэтому перед чтением или изменением содержимого установи нужную вкладку явно.

Можно создать несколько быстрых чертежей: у каждого своя вкладка и независимое содержимое, они не конфликтуют друг с другом. При смене активной модели проекта эти вкладки сохраняются. Вкладка является динамической: пользователь может закрыть ее крестиком.

## Инструменты

Для создания и выбора вкладки используй инструменты домена `[ПРОЕКТ]`:

- `project_add_quick_drawing` — создать новое окно (вкладку) с пустым быстрым чертежом в активном проекте. Обязательный параметр `windowName` задает непустое имя вкладки. Имя длиннее 20 символов сокращается до первых 17 символов с многоточием; итоговое имя должно быть уникальным среди окон проекта. Ответ содержит данные созданного окна, включая `Name` и `UID`.
- `project_get_active_windows` — без параметров получить `windowCount` и список `windows`. Для поиска быстрых чертежей отбирай окна с `IsQuickDwg = true`, затем выбирай нужное по `Name` и `UID`. Флаг `Dynamic = true` означает возможность закрыть вкладку, но сам по себе не определяет быстрый чертеж.
- `activate_window` — активировать найденную или созданную вкладку, передав ее `UID` в параметре `uid`. Используй фактический UID из ответа инструмента, не конструируй его по имени.
- `close_window` — закрыть вкладку по `uid`, если это требуется пользователю. Перед закрытием проверь целевое окно и `Dynamic = true` по актуальному списку.

Для содержимого используй обычные инструменты домена `[ЧЕРТЕЖ]` по их доступным схемам параметров. Например, `dwg_create_line`, `dwg_create_polyline` и `dwg_create_circle` создают геометрию, `dwg_create_text` и `dwg_create_mtext` — пояснения, `dwg_add_layer` — слой. Специальные инструменты редактирования быстрых чертежей не нужны.

`dwg_get_active_drawing_info` возвращает сведения об активном чертеже, включая число сущностей, границы и слои. Для проверки конкретных объектов доступен `dwg_get_entities_info`. Для показа нужной области используй `cad_view_zoom` из домена `[ВИДОВОЙ ЭКРАН]`; этот инструмент меняет отображение, а не геометрию.

## Порядок работы

1. Определи, что требуется показать. Получи список окон через `project_get_active_windows`: для новой демонстрации выбери свободное понятное имя, желательно не длиннее 20 символов. Если пользователь просит продолжить существующий быстрый чертеж, найди его по актуальному списку и `IsQuickDwg = true`.
2. Для нового чертежа вызови `project_add_quick_drawing` с `windowName` и сохрани возвращенный `UID`. Создание новой вкладки не заменяет проверку контекста редактирования.
3. Вызови `activate_window` с `uid` целевой вкладки. Убедись по ответу, что `IsQuickDwg = true` и `HasDrawing = true`. Только после успешной активации выполняй операции с чертежом.
4. Создай или измени демонстрационное содержимое инструментами домена `[ЧЕРТЕЖ]`. При необходимости прочитать исходные данные модели сделай это в ее контексте, затем вернись на вкладку быстрого чертежа перед добавлением демонстрационной геометрии.
5. Проверь результат по ответам инструментов и сведениям о созданных сущностях. При `HasCadView = true` настрой отображение через `cad_view_zoom` по фактическим границам геометрии. Оставь вкладку с результатом активной, чтобы пользователь видел демонстрацию.

## Взаимодействие с пользователем

Пользователь может самостоятельно рисовать или изменять примитивы в быстром чертеже, а агент — получать результаты через MCP-инструменты домена `[ЧЕРТЕЖ]` и использовать их для дальнейшей работы. Например, пользователь рисует контур, а агент читает его геометрию и строит пояснение или анализирует заданную форму.

Создай или выбери быстрый чертеж по порядку выше, активируй его вкладку и объясни пользователю, что нужно нарисовать. Дождись сообщения о завершении ввода. Затем снова активируй нужную вкладку и получи актуальное содержимое: `dwg_get_active_drawing_info` — число сущностей, `dwg_get_entities_info` — сведения о сущностях по диапазону индексов, `dwg_get_active_space_entity` — данные конкретного примитива по полученному `guid`. Для непустого чертежа допустимые индексы — от `0` до `entitiesCount - 1`; при отсутствии сущностей не запрашивай диапазон.

Опирайся на прочитанную геометрию, а не на предположение о том, что пользователь нарисовал. Если в чертеже уже были примитивы, отличай их от пользовательского ввода по актуальным данным; при неоднозначности уточни, какие объекты использовать.

## Особенности и ошибки

- Список окон не содержит признака активной вкладки. Наличие быстрого чертежа в списке или успешное создание окна не означает, что дальнейшее редактирование уже направлено в него: опирайся на успешный `activate_window`.
- После смены модели или вкладки заново выбери быстрый чертеж перед продолжением работы. Не создавай замену только из-за смены модели: существующая вкладка сохраняется.
- Если подходит несколько быстрых чертежей и из задачи нельзя определить нужный, уточни выбор до редактирования. Не используй случайную динамическую вкладку.
- При конфликте имени выбери другое имя с учетом сокращения. После неоднозначной ошибки создания сначала обнови список окон, чтобы не создавать дубликат повторным вызовом.
- Если пользователь закрыл вкладку, ее прежний UID больше нельзя использовать. Получи актуальный список и создай новый быстрый чертеж, только если это нужно для продолжения задачи; не считай его восстановлением прежнего содержимого.
- Если MCP-сервер или нужный инструмент недоступен, сообщи, какое действие выполнить не удалось. Не подменяй демонстрацию изменением проектного чертежа.

## Проверка результата и ответ пользователю

Убедись, что результат находится в выбранной вкладке с `IsQuickDwg = true`, а ответы инструментов подтверждают нужную геометрию и пояснения. Сведения об активном чертеже относятся к быстрому чертежу только после активации его вкладки.

В ответе кратко назови вкладку и опиши, что на ней показано. Не закрывай ее после демонстрации автоматически. При необходимости поясни, что пользователь может закрыть быстрый чертеж крестиком вкладки.
